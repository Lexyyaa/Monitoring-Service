# P00 chore/bootstrap 환경 구성

- 한 일
  - 설계 문서와 작업 규칙을 옮겼다. 작업 상태는 작업 계획 체크박스로 관리한다.
  - 백엔드(Spring Boot 3.5), 프론트엔드(React, Vite), PostgreSQL Compose를 구성했다.
  - 백엔드 테스트는 테스트 전용 DB `monitoring_test`에만 접속한다.
- 확인
  - 백엔드 테스트 2건, 프론트 테스트 1건, E2E 1건 통과
  - 서버와 화면이 실제로 뜨는 것을 확인했다.
- 결정
  - 과제의 "상태" 필터는 이상 심각도로 해석했다.
  - 트리 `PATH`는 펼쳐서 도달할 수 있는 하위만 근거로 한다.
