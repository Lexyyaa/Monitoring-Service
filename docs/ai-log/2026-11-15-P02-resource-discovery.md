# P02 feat/resource-discovery 검색과 필터

- 한 일
  - Cluster·Node·Namespace·Pod 이름 검색 API와 화면을 구현했다. 결과를 고르면 트리 경로를 연다.
  - 심각도 필터를 트리와 검색 API, 화면에 연결했다.
  - `namespaces`, `pods` 이름에 GIN 인덱스를 추가했다.
- 확인
  - 백엔드 테스트 57건, 프론트 테스트 29건, E2E 6건 통과
  - 3자 검색 API p95가 20.69ms에서 5.17ms로 줄었다.
- 결정
  - PATH는 트리로 도달할 수 있는 하위만 근거로 한다. Pod 없는 Namespace는 Cluster의 PATH 근거가 아니다.
  - 필터 불일치 안내는 선택 당시가 아니라 현재 트리 행의 MATCH·PATH로 판단한다.
  - 검색어 길이는 앞뒤 공백을 지운 뒤 검사한다.
  - 경로를 열지 못하면 트리 영역에 안내 문구를 보여 준다.
- 남은 일
  - 1~2자 검색은 인덱스를 쓰지 못한다. 목표 안이라 그대로 둔다.
