# V2-01 검색 입력 리렌더 개선

## 한 일

- "검색어를 입력할 때마다 화면이 계속 그려진다"는 피드백의 원인을 찾았다.
- v2 계획 문서([docs/v2/README.md](../v2/README.md))를 만들고 스펙, 설계, 작업, 결과를 한 섹션에 정리했다.
- 검색 훅을 `ResourceSearch` 안으로 옮겼다.
- 검색 조회에 `keepPreviousData`를 넣고, 이전 결과를 보여 주는 동안 "검색 중"을 띄웠다.
- 렌더 횟수, 이전 결과 유지 컴포넌트 테스트와 입력 반응 측정 스크립트를 추가했다.

## 확인

- 10글자 입력 동안 검색 밖 컴포넌트 렌더가 10번에서 0번이 됐다. 응답 뒤 1번은 남는다.
- 2,220행에서 한 글자당 평균 반응이 14.1~15.2ms에서 5.5~6.8ms가 됐다.
- 새 테스트 두 건은 수정 전 코드에서 실패하고 수정 후 통과했다.
- format, build, 테스트 50건, E2E 10건이 통과했다. 전후 측정과 E2E는 PR #10 머지 전 main에서 했다.

## 결정

- 응답 뒤 1번 렌더는 마지막 갱신 시각 표시 때문이라 남겼다.
- `React.memo`로 막는 대신 상태 위치를 옮겼다. 원인을 없애는 쪽이다.
- v2 작업은 파일을 늘리지 않고 `docs/v2/README.md` 섹션으로만 쓴다.
- 미커밋 성능 작업(`perf/large-tree`)과 섞이지 않게 main에서 `fix/search-rerender`로 분리하고 다시 쟀다.

## 남은 일

- Profiler 측정과 PERF-T03 재측정은 하지 않았다.
- 최대 반응 시간이 어느 입력에서 나오는지 보지 않았다.
