# P03 feat/resource-refresh 갱신과 신선도

- 한 일
  - 30초 폴링과 수동 새로고침을 구현했다. 화면에서 쓰는 조회만 다시 부른다.
  - 갱신이 실패하면 이전 데이터를 유지하고 영역마다 안내와 재시도를 보여 준다.
  - 스크롤하는 동안에는 폴링을 미룬다.
- 확인
  - 백엔드 테스트 59건, 프론트 테스트 41건, E2E 10건 통과 (DB 변경 E2E는 임시 DB 컨테이너에서 실행)
  - 스크롤 중 폴링이 겹친 구간이 16fps에서 60fps로 바뀌었다.
- 결정
  - 마지막 성공 조회 시각은 가장 최근 값만 보여 준다. 늦게 끝난 예전 요청이 시각을 되돌리지 않는다.
  - 탭이 보이지 않으면 폴링을 건너뛴다.
  - 알림 묶기와 분기 조회 목록 고정은 측정에서 효과가 없어 되돌렸다.
- 남은 일
  - 분기 220개를 펼친 갱신은 응답 후 반영이 약 455ms다. 여러 분기를 한 번에 받는 API가 필요하다.
