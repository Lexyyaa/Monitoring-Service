# P01 feat/resource-explorer 트리 탐색과 상세

- 한 일
  - Flyway 스키마, 엔티티, 목표 규모 시드와 검증 SQL을 추가했다.
  - 트리 직접 하위 조회 API 4개와 상세 API, 공통 오류 응답을 구현했다.
  - 지연 조회 트리, 가상 스크롤, 오른쪽 상세 패널을 구현했다.
- 확인
  - 백엔드 테스트 39건, 프론트 테스트 15건, E2E 4건 통과
  - 2,220행을 펼쳐도 DOM 행은 40개 이하였다.
- 결정
  - 엔티티가 스키마를 검증하므로 스키마(P01-02)를 엔티티(P01-01)보다 먼저 커밋했다.
  - `ErrorCode`에서 HTTP 상태를 빼고 오류 처리기에서 대응했다. Domain이 HTTP를 모르게 한다.
  - `fetchedAt`은 `lastUpdatedAt`과 같은 UTC 형식(`Z`)으로 응답한다.
  - 오류 문구는 서버 안내만 보여 주고, 네트워크 오류 원문은 기본 문구로 바꾼다.
  - 오류가 난 분기도 접을 수 있게 했다.
