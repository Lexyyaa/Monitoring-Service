# 문서 정리

- 한 일
  - AGENTS 세 개를 짧은 규칙 위주로 다시 썼다.
  - README를 결과와 링크 위주로 다시 쓰고, 넓은 표를 하위 불릿으로 바꿨다.
  - 보고서 세 개 맨 위에 목적과 맥락을 두고, 최종 결과와 측정 이력을 나눴다.
  - 설계 문서의 넓은 표를 불릿으로 바꾸고, 테스트 파일 이름과 링크를 실제와 맞췄다.
  - 시스템 구성도와 ERD를 새로 그리고, 실행 구성 그림을 추가했다.
- 확인
  - ERD의 컬럼을 Flyway V1 스키마와 대조했다. 네 테이블 41개 컬럼이 일치한다.
  - 그림을 렌더링해 선과 글자가 겹치지 않는 것을 확인했다.
- 결정
  - README는 결과만 쓰고, 측정값과 과정은 보고서와 ADR에 둔다.
  - 아쉬운 점은 현재 방식, 어려움, 개선 방향 순서로 쓴다.
- 남은 일
  - 페이징과 대량 목록 처리 검증은 별도 세션에서 진행한다.
